# M07 — Today planner
Depends on: M06   |   Refs: Master Spec §11

## Data
`app.planner_config` (weights, age session lengths), `app.today_plans(student, local_date, version, generated_at)`, `app.today_plan_items(kind, ref_id, minutes, priority, reasons jsonb, status)`.

## API
- `GET /v1/students/:id/today`
- `POST /v1/students/:id/today/recalculate`
- `POST /v1/today-items/:id/start|complete|skip`

## Rules (`packages/domain/planner`)
- Priority formula per §11, with weights in config. Every item carries `reasons[]`.
- Candidate generators: ParentTasks, Homework, ExamPrep (exam within 14 days), WeakPrerequisite, DueReview, ReadingGoal and ActivityGoal (task-based until M16/M18).
- Time budget comes from timetable free time plus a parent setting. Default session lengths by age: G1-3 15', G4-6 25', G7-9 35', G10-12 45'.
- The plan regenerates on day start (pg_cron per timezone), when a task is created or approved, and when a session finishes. Ordering is deterministic.
- Learning items deep-link to sessions and complete as SYSTEM_VERIFIED.

## UI (mobile)
- Child home = Today: cards with duration, reward hint and cap bar.
- Parent: the child's Today with reasons, and the ability to pin or remove items.

## Acceptance
- An exam in 3 days on 2 skills → exam-prep items rank above optional tasks.
- Finishing a session refreshes Today without a manual reload (query invalidation).
