# M06 — Practice sessions, mastery, T0 hints, template variants
Depends on: M04, M05, X01, X02   |   Refs: Master Spec §10, §29 (second slice); ARCHITECTURE §3, §5

## Data (schema `app`)
- `learning_sessions(student, skill_ids, mode PRACTICE|REVIEW|DIAGNOSTIC, client_uuid)`
- `answer_attempts(item_id, variant_seed, response, is_correct, hints_used, response_ms, client_uuid)`

- `mastery_config`

## API
- `POST /v1/learning/sessions`, `GET /v1/learning/sessions/:id/next`
- `POST /v1/learning/sessions/:id/answers`, `POST /v1/learning/sessions/:id/hint`, `POST /v1/learning/sessions/:id/finish`
- `GET /v1/students/:id/knowledge-map`, `GET /v1/students/:id/learning-path`
- `POST /v1/items/:id/report`

## Rules (`packages/domain/mastery`)
- `MasteryStrategy` interface. `WeightedMasteryStrategy` implements §10.3, with weights and thresholds in config. Display states follow §10.2. Retained requires a correct review at least `retention_min_days` after Mastered.
- Diminishing returns within `min_interval_sec`. Hints reduce the independence weight.
- Item selection:
  - target difficulty ±1;
  - prefer unseen items; for TEMPLATE items use a new seed;
  - 70% current skill, 30% due reviews;
  - diagnostic of 8-12 adaptive items for the first session on a topic.
- **T0 help**: the hint endpoint returns the next of the 4 pre-generated hints. After a wrong answer, the matching `distractor_feedback` is shown. The worked solution is shown after level 4 or at session end. No AI calls in this module.
- Spaced review with SM-2-like intervals from config; `forgetting_risk` is computed.
- Finishing a session emits `LearningSessionFinished`. M04 grants XP via rule `learning.correct_answer`. XP is not mastery.
- Without `EDUCATION_ANALYTICS` consent: sessions work, only aggregates are stored.
- Attempts feed `library.item_stats` through a nightly aggregate. No student identifiers are copied into the library schema.

## UI (mobile, child)
Learn tab → knowledge map → session screen:
- renderers for every M05 item type except `written` (hidden until M17): choice, numeric keypad, fill blank, word bank, picture choice, drag ordering, matching, true/false, spelling choice;
- passage/group view: the stimulus stays visible (collapsible) while its items are answered;
- math rendered with KaTeX (react-native-math-view or WebView KaTeX, chosen in the PLAN); SVG via react-native-svg;
- **read-aloud**: on-device TTS (`expo-speech`, Vietnamese or English voice from `tts_lang`) reads stem, options and hints. It is on by default when the subject profile or student grade ≤3 says so, and there is a speaker button on every item;
- **Grade 1-3 mode**: large touch targets, minimal typing, sessions of ~15 minutes, encouraging feedback;
- hint ladder button;
- feedback for each wrong option;
- "báo lỗi câu hỏi" button;
- session summary.

Parent: per-skill state list.

## Acceptance
- Diagnostic on "Phân số" → 10 correct answers → Proficient.
- With hints, the mastery delta is smaller.
- A TEMPLATE item shows different numbers on retry, and correctness is judged against that seed.
- A due review appears the next day (injected clock).
- XP is granted once per session.
- A Grade 2 child completes a Toán 2 session using only taps, with every item read aloud in Vietnamese.
- A passage group from a fixture shows its passage and 3 linked items.
