# M05 — Curriculum & shared content library core
Depends on: M02   |   Refs: Master Spec §8, §31.4, §32; ARCHITECTURE §3; CONTRACT D5, D6; docs/CONTENT_PLAN_vi.md

## Goal
Store the GDPT skill backbone and a global, reusable item library that supports all 8 launch libraries (Grade 2 and Grade 6: Math, Vietnamese/Literature, English, Science). Content is loaded from reviewed packages. This module's tables hold no personal data.

## Data (schema `library`)
- **Curriculum:** `curriculum_versions`, `curriculum_nodes(level GRADE|SUBJECT|DOMAIN|TOPIC|LESSON|OBJECTIVE|CONCEPT|SKILL, code unique per version, title_vi, description, gdpt_requirement_ref, weight, status)`, `knowledge_edges(type per §8.2)`, `book_series`, `book_lesson_mappings`.
- **`subject_profiles`**: `grade, subject, template_share, group_share, written_share, read_aloud_default, image_level, item_type_mix jsonb`. Seeded from `docs/CONTENT_PLAN_vi.md` §3 for the 8 launch libraries.
- **`items`:**
  - `kind STATIC|TEMPLATE`, `skill_ids`, `difficulty 1-5`, `cognitive_level L1-L5`;
  - `type`: single_choice, multi_choice, numeric, fill_blank, word_bank, picture_choice, ordering, matching, true_false, spelling_choice, written;
  - `stem_md` (KaTeX allowed), `options jsonb` (text and/or media id per option), `answer jsonb`, `explanation_md`;
  - `hints jsonb[4]`, `worked_solution_md`, `distractor_feedback jsonb` (per option + misconception tag), `misconception_tags`;
  - `rubric jsonb` (written items only);
  - `tts_text` and `tts_lang (vi|en)` on the stem, plus per option and per hint;
  - `group_id`, `group_order`;
  - `source_refs`, `provenance` (models, prompt versions, verifier verdicts);
  - `status DRAFT|AI_GENERATED|VALIDATING|NEEDS_REVIEW|APPROVED|PUBLISHED|REJECTED|ARCHIVED`, `version`.
- **`item_groups`:** `stimulus_kind PASSAGE|POEM|DIALOGUE|PICTURE_SCENE|EXPERIMENT, title, body_md, tts_text, media_ids, word_count, genre, source_kind ORIGINAL_AI|PUBLIC_DOMAIN|LICENSED, source_note`.
- **`media_assets`:** `kind ICON|SVG|IMAGE, storage_path or inline_svg, alt_vi, license, attribution, review_status`.
- **`item_templates`** (1:1 with TEMPLATE items): `params` spec (name, type, range/set, step, or word list), `constraints` (math.js boolean expressions), `answer_expr`, `render` (stem/options/tts with placeholders), `distractor_exprs` (wrong answers derived from misconceptions). Word-list params cover spelling and vocabulary templates.
- **`item_stats`:** attempts, p_correct, median_ms, hint_rate, report_count, calibrated_difficulty, last_computed_at.
- **`item_reports`:** reason, item, variant seed. No free text is stored with the child's identity.
- **`tutor_answers`:** filled by M15.

## Variant engine (`packages/domain/library/variants.ts`)
`renderVariant(template, seed)` is deterministic:
1. A seeded PRNG picks params and retries until the constraints hold. After 50 failed tries the template is flagged.
2. The answer and distractors are computed with math.js (numeric) or looked up in the word lists (language).
3. Stem, options and TTS text are rendered.

The same function runs in the API and offline in the mobile app.

## Library package format (shared with X01-X08 and M14)
`library/<curriculumVersion>/<grade>-<subject>/` contains:
- `manifest.json` (counts, checksums, models, reviewer)
- `curriculum.json`, `edges.json`, `mappings.json`
- `groups.jsonl`, `items.jsonl`, `templates.jsonl`
- `media/` (SVG files + `media.jsonl`)

JSON Schemas live in `packages/contracts/library/`.

## API / tools
- `pnpm library:validate <path>`.
- Admin: `POST /v1/admin/library/import` (upload zip → dry-run diff → apply).
- Admin screens:
  - curriculum tree browser;
  - item list filtered by skill, status, kind, type and level;
  - item editor with live KaTeX, media preview, TTS preview (browser speech synthesis) and variant re-roll;
  - group editor.
- Child-facing reads are added in M06. Only `APPROVED|PUBLISHED` items and groups are reachable from child endpoints.

## Rules
- Import is idempotent by code or item hash. Referenced nodes and items are archived, never deleted.
- No cycles in PREREQUISITE_OF and no orphan skills. A skill is active only with ≥2 approved items.
- SVG media are sanitised on import (no scripts, no external refs).
- `PUBLIC_DOMAIN` and `LICENSED` groups require a `source_note`.
- Coverage report per grade-subject: items per skill, per level, per type, TEMPLATE share, group share, total vs target 500.

## Acceptance
- Fixtures for Toán 6 (templates), Toán 2 (SVG counting, read-aloud) and Tiếng Việt 2 (passage group, spelling template, picture choice) run dry-run → apply → re-import as a no-op.
- A fixture with a cycle is rejected with a readable error.
- Template property tests pass for 10,000 seeds.
