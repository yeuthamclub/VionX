# M08 — Parent dashboard & gradebook
Depends on: M07   |   Refs: Master Spec §7, §12

## Data
`app.school_assessments` (fields §12), `app.school_assessment_skill_mappings`, and summary tables refreshed by the worker on events.

## API
- `GET/POST /v1/students/:id/school-assessments`
- `PATCH/DELETE /v1/school-assessments/:id`
- `GET /v1/students/:id/dashboard?range=`
- `GET /v1/household/overview`

## Rules
- School grades and app mastery are never merged; they are shown side by side.
- Every interpretive widget shows a data sufficiency label (`INSUFFICIENT|LOW|OK`) with thresholds from config.
- Only parents can edit grades, and every edit is audited.
- Attachments use signed upload. No OCR.

## UI (mobile, parent)
- Home: one card per child (Today completion, streak, Coin today/week, skills improving or at risk, upcoming exams).
- Child detail tabs: Overview, Learning, School (table + trend chart with victory-native), Tasks & rewards.
- Fast grade entry form.

## Acceptance
Full §43 flow as a Maestro suite on two emulators (parent device, child device):
parent signs up → 3 children → timetable + tasks → child logs in → task + learning → XP → Coin within cap → dashboard updates.
A grade entry appears next to mastery.
