# M13 — Source search by skill + retrieval eval
Depends on: M12   |   Refs: Master Spec §31.5, §33.9; CONTRACT D9

## Data
`library.content_chunks(book_version, lesson_node, skill_ids, content_type, page_start, page_end, text, context_header, review_status)`, a generated `tsvector` with `unaccent` + a simple Vietnamese config, GIN indexes on the tsvector and `skill_ids`.

## Rules
- Chunks follow block roles (definition, explanation, worked example, exercise group, table), 150-500 tokens, never crossing lessons. `context_header` example: "Toán 6 · Chương 2 · Bài 5 Phân số · Ví dụ 2 · tr.34".
- `retrieve({grade, subject, skillIds, query, types})`:
  1. filter by grade/subject/skill/type and APPROVED;
  2. rank with `ts_rank_cd`, plus a boost for an exact skill match and for definition/example types;
  3. return the top 3-5 with page refs.
- `EmbeddingProvider` interface exists but is unused. Turning on pgvector requires an ADR showing the eval gain.

## Evaluation
`tools/eval/retrieval_grade6_math.jsonl`: ≥60 student-style Vietnamese queries with expected lesson/pages. `pnpm eval:retrieval` reports recall@5 and MRR. Target recall@5 ≥ 0.85. If it is missed, the report proposes an ADR (synonym dictionary first, embeddings second).

## UI (admin)
Chunk Inspector + Test Retrieval with scores.

## Acceptance
Eval target met, or an ADR filed. p95 retrieve < 200 ms inside the API function.
