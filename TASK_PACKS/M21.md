# M21 — Strength insights
Depends on: M16-M19 + ≥8 weeks of data   |   Refs: Master Spec §19, §21.4

## In scope
- A weekly worker job writes `app.talent_domain_snapshots` for each domain: Math/Logic, Language/English, Reading, Physical activity, Consistency.
- Each snapshot has an indicator (0-100) built from documented features, plus confidence, data sufficiency, an evidence list and a trend. XP and Coin are never used.
- Parent UI shows the evidence and next opportunities (links to M19/M20).
- Optional weekly parent summary from a `claude-haiku-4-5` batch job, separating observed / inferred / recommended / insufficient. Requires `AI_PERSONALIZATION` consent.
- Copy is checked against §19: no labels and no career determinism.

## Acceptance
- A child with less than 4 weeks of data shows "chưa đủ dữ liệu".
- Every indicator lists its evidence.
- The copy checklist passes.
