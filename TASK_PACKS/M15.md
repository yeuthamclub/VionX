# M15 — AI tutor T1-T3 + Q&A library growth
Depends on: M14   |   Refs: Master Spec §21.2, §31.6; ARCHITECTURE §5

## Tiers
- **T0** (already in M06): pre-generated hints, distractor feedback and worked solutions. No change here.
- **T1**: a free-form question → normalise → full-text search in `library.tutor_answers` of the same skill (APPROVED only). A strong match is answered immediately at zero AI cost.
- **T2**: no match → `claude-haiku-4-5`, streaming. The cached system prompt holds the tutor rules and the skill's approved chunks (M13). The answer must cite chunk ids. Without a supporting chunk the tutor says "chưa có tài liệu cho phần này" and writes a `content_gaps` row.
- **T3**: escalate to `claude-sonnet-5-5` when T2 reports low confidence or on the child's third follow-up in the same thread.

## Rules
- Gated by `AI_PERSONALIZATION` consent (+ assent for ages ≥7). Without consent, only T0 and T1 are available.
- Daily free-form quota per child (default 5, parent-visible, configurable per plan); returns `TUTOR_QUOTA_REACHED` when exceeded.
- The prompt carries a pseudonymous student ref, grade and skill state only.
- Never give the final answer to the current item before hint level 4.
- **Library growth**: each T2/T3 answer is stored as a candidate in `tutor_answers` (anonymised: question text cleaned of names/numbers that identify the child, no student id). Candidates enter an admin review queue. Approved answers serve T1 for all students.
- Unsafe or off-topic → friendly refusal. Parents see counts, not content.
- Cost per tier is tracked in `ai_runs` and shown on `/system`.

## UI
- Child: "Hỏi VionX" sheet in sessions with source chips ("SGK Toán 6, tr.34") and the remaining quota.
- Admin: tutor answer review queue, content-gap queue, audited transcript viewer.

## Acceptance
- `tools/eval/tutor/` 30 scripted conversations: 100% cite or decline, 0 final answers before level 4.
- A repeated question is served by T1 after approval.
- The report gives average cost per free-form question and the T1 hit rate.
