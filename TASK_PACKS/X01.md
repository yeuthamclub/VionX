# X01–X08 — Launch library build scripts (Grade 2 + Grade 6, 8 × 500 items)
Depends on: M05 (X01); X01 (X02); GATE A, then the previous run (X03–X08)   |   Refs: docs/CONTENT_PLAN_vi.md, docs/BOOK_PIPELINE_vi.md §6-7, docs/COST_OPTIONS_vi.md; ARCHITECTURE §3-4

## Goal
One reusable script set (`tools/library-build/`) that builds a reviewed library package of **500 items** for one grade-subject, using Claude batch calls and spreadsheet review, before the full pipeline (M10-M14) exists. Each library is a separate run with its own subject profile.

| Run | Library | Phase | Profile notes (CONTENT_PLAN §3) |
|---|---|---|---|
| X01 | Toán 6 (`MATH.6`) | A | ≥40% TEMPLATE, SVG geometry |
| X02 | Toán 2 (`MATH.2`) | A | ≥50% TEMPLATE, SVG counting/clocks/shapes, read-aloud |
| X03 | Tiếng Việt 2 (`VIET.2`) | after GATE A | passages ~40%, spelling templates, picture choice, read-aloud |
| X04 | Ngữ văn 6 (`LIT.6`) | after X03 | passages ~60% by genre, short writing tasks |
| X05 | Tiếng Anh 6 (`ENG.6`) | after X04 | readings/dialogues ~35%, listening via TTS |
| X06 | Tiếng Anh 2 (`ENG.2`) | after X05 | picture vocabulary, short dialogues, English read-aloud |
| X07 | KHTN 6 (`SCI.6`) | after X06 | unit/measurement templates ~25%, experiment scenarios, SVG diagrams |
| X08 | TN&XH 2 (`NATSOC.2`) | after X07 | picture scenes, situations, read-aloud |

Rule: a run starts only when the previous library is reviewed. Lessons learned (common rejection reasons) are added to the prompt notes of the next run.

## Inputs (already in hand)
- The source PDFs: the unified 2026-2027 national series (Kết nối tri thức; Global Success for English), SGK + SGV for Grade 2 and Grade 6, SBT for Grade 2 only. They are image-only scans with no text layer. Scripts read them from the owner's folder (`/Volumes/ViTu/VionX/Sach giao khoa`) or from the private bucket `sources/<grade>-<subject>/` after upload. The series name is recorded in `manifest.json`.
- GDPT 2018 program texts (TT 32/2018) in `/mnt/project-files/sources/gdpt/`: Toán, Ngữ văn (incl. Tiếng Việt 1-5), TN&XH, KHTN, Tiếng Anh 3-12.
- Tiếng Anh 2 has no program text: its backbone is built from the Global Success 2 SGK + SGV following Công văn 681/2020 (listening and speaking first).

## Scripts (`pnpm library:build <grade-subject> <step> [--topic CODE]`)
1. `textlayer`: extract the text layer per page (pdf.js). Mark pages as good, legacy-encoding, scanned or formula-heavy. Hard pages go to Haiku 4.5 (Batch). For the current image-only SGK set this means every page (about US$0.003 per page).
2. `backbone` (Sonnet 5.5): GDPT program text (for ENG.2: the SGK + SGV, see Inputs) → DOMAIN/TOPIC/OBJECTIVE/SKILL tree with codes `<SUBJ>.<grade>.<DOMAIN>.<TOPIC>.<SKILL>` and weights.
3. `map` (Sonnet 5.5): SGK table-of-contents pages + backbone → lesson → skill mappings.
4. `edges` (Sonnet 5.5): prerequisite edges with reasons.
5. `plan`: allocate 500 items across skills with the ARCHITECTURE §3 rule plus the subject profile (TEMPLATE share, item-type mix, group share, written share). Output `plan.csv` for owner approval.
6. `passages` (language and science runs; Batch, Sonnet 5.5): write the planned stimuli (`item_groups`):
   - original passages, poems, dialogues and experiment scenarios at the target genre, length and reading level;
   - or a PUBLIC_DOMAIN text (ca dao, tục ngữ, truyện cổ tích, out-of-copyright authors) with a `source_note`;
   - never SGK reading texts copied verbatim.
7. `media` (Batch, Sonnet 5.5): simple SVGs for counting, shapes, clocks, diagrams and picture choices, or a licensed icon id. Rendered to PNG locally for the reviewer and sanitised.
8. `generate` (Batch, Sonnet 5.5): per skill (and per group), the planned items with hints[4], worked solution, distractor feedback, misconception tags, `tts_text`/`tts_lang` and, for written items, a rubric. Templates use math.js expressions (Math, KHTN) or word lists (spelling, vocabulary). SGK/SGV page text is attached as reference only.
9. `check` (code):
   - schema;
   - exactly one correct answer (except multi_choice and written);
   - math.js re-computation;
   - KaTeX parse;
   - template constraint test over 1,000 seeds;
   - n-gram overlap with SGK/SBT text (items and passages);
   - duplicate check by normalised text;
   - TTS text present where the profile requires read-aloud;
   - reading level of passages (word count, sentence length) within the profile range;
   - SVG renders and passes sanitising.
10. `verify` (Batch, Haiku 4.5): blind solve, grade hints, check age-appropriateness of passages and pictures. Disagreements → `dispute` (Batch, Opus 5.5).
11. `review-export` → `review.csv` (Google Sheets) with verdicts, flags, passage text and picture links; `review-import` applies APPROVED/REJECTED/EDITED. Rejected slots are regenerated once.
12. `package`: build and validate the library package (M05 format), upload it to Storage, and print cost from `ai_runs`.

Run topic by topic, starting with one topic end to end for each new library.

## Reviewers
- Math (X01, X02) and science (X07, X08): the product owner can review.
- Language (X03–X06): a teacher or a parent with subject knowledge, because passages, spelling and writing rubrics are the hardest part to check automatically.

## Acceptance (per run)
- `pnpm library:validate` passes with ≥480 approved items, and every active skill has ≥2 items.
- Profile shares (TEMPLATE, groups, read-aloud, written) are within ±5 points of the subject profile.
- No passage or item exceeds the n-gram overlap threshold with SGK text; every PUBLIC_DOMAIN group has a `source_note`.
- The report lists per-skill counts, type mix, TEMPLATE share, verifier disagreement rate, rejection rate, AI cost and review hours. These numbers update `docs/COST_OPTIONS_vi.md` after X01.
