# M23 — Hardening & Google Play release
Depends on: M22   |   Refs: Master Spec §27

## In scope
- **Security:**
  - authorization matrix tests for every API route;
  - dependency and secret scanning;
  - OWASP MASVS-L1 checks for the app (secure storage, no secrets in the bundle, certificate pinning decision recorded);
  - OWASP ASVS L2 subset for the API.
- **Privacy:** export/delete verified end to end.
- **Accessibility:** TalkBack labels, font scaling, contrast.
- **Load test:** k6 against staging for 1,000 households.
- **Google Play:**
  - Families policy and Teacher Approved readiness checklist;
  - Data safety form;
  - content rating;
  - target audience (mixed: parents and children);
  - store listing in VionX brand;
  - closed testing → production rollout plan.
- Trademark and domain confirmation recorded.
