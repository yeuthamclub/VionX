# M11 — Page extraction (text layer first, Claude for hard pages)
Depends on: M10   |   Refs: Master Spec §31.2-31.3, §33.5; CONTRACT D7-D8; docs/BOOK_PIPELINE_vi.md §4

## Stages
1. `TEXT_PAGES` (no AI): pages routed TEXT are normalised (NFC, hyphenation joins, repeated header/footer removal) and split into blocks with rules (numbered headings "Bài", "§", "Ví dụ", "Bài tập", "Định nghĩa", boxed text by font cues from pdf.js).
2. `AI_PAGES` (Batch, `claude-haiku-4-5`): each 10-page split PDF is sent as a document block with the cached system prompt `extract_pages@vN` and the structured schema `CanonicalPages`:
   `pages[{page, blocks[{type heading|paragraph|definition|theorem|example|exercise|solution|table|figure_caption|note, text, latex[], table_md?, figure_desc?}], confidence}]`.
3. `VALIDATE_PAGES` (code):
   - every page present exactly once;
   - KaTeX parses all LaTeX;
   - Vietnamese dictionary hit rate;
   - for pages that have some text layer, similarity to that layer above a threshold (hallucination guard).

   Failing pages are re-read alone with `claude-sonnet-5-5` (stage `RETRY_PAGES`). If they still fail → `NEEDS_REVIEW`.
4. `ASSEMBLE`: canonical document JSON (§31.2 + block ids) to Storage, `source_blocks` rows, `human_corrections` re-applied.

## Quality
- Golden set: 30 hand-checked Grade 6 Math pages (text, scanned, formula-heavy, table) under `tools/golden/`.
- `pnpm eval:extract` reports character error rate, LaTeX exact match and cost per page per model, and compares against the stored baseline.
- Any model change in `ai_task_config` for extraction requires a green eval in the PR.

## UI (admin)
Book Inspector → Pages tab:
- preview beside rendered blocks;
- edit block (saved as a correction);
- force route (TEXT/AI) and re-run a page.

## Acceptance
- A digital and a scanned Grade 6 Math PDF both become canonical documents with page provenance.
- The report includes: share of pages handled without AI, golden-set metrics and total cost.
